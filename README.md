# 🔑 Katniny+
How Katniny Studios processed Katniny+ subscriptions securely, as well as checks the status and allows cancelation.

## ❓ How does it work?
Our payment system uses [Stripe](https://stripe.com/) and is hosted (for now) by [Vercel](https://vercel.com/). How it's processed, checked and canceled depends on the product. Please check, if source code is available, how it works there.

## 💫 What uses this API?
Currently, the following uses this system: 
- TransSocial

You may check the benefits of getting a Katniny+ subscription for a platform at https://transs.social/settings?tab=subscription.

A proper support page will be available for this soon on our website.
